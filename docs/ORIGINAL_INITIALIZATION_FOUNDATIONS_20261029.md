# Initialization foundations (not playable)

Native module dispatch now follows the installed 735-module order. The static read-only catalog records 3,211 hook names and source hashes. `hook_register` and `__MAGIC__` are modeled with explicit per-call parent/caller context; cross-module calls reach the final override, direct calls from the immediate override reach the parent implementation, and missing implementations throw rather than silently reverting to a basic effect. Ten source PHP dispatcher cases plus async isolation checks validate the dispatch rules. Module init functions and the remaining hook implementations are not automatically ported by catalog generation.

All eight enabled `init_enter_battlefield_items` overrides and their exact starting-pool selection hooks are implemented. Eleven raw source pools preserve headers, line endings, duplicates and retries. Three hundred source PHP fixtures compare inventory and every requested RNG interval/result across modes, genders and ascension levels. Nested compound attributes retain the original nonstandard base64 encoding.

The PHP 7.4 MT19937 stream, unbiased 32/64-bit bounded sampling, rand reversed bounds, shuffle, and array_rand including deleted hash buckets are native TypeScript. Fixtures compare six seeds, each with 1,300 raw draws, 1,200 bounded draws, five shuffles and nine array-key selections. Snapshot/restore preserves draw position. This generator is for gameplay and never credentials. Reference algorithms were read from php-src PHP-7.4 ext/standard/mt_rand.c and array.c, and verified against the server's PHP 7.4 executable.

Original skill two-character IDs and base64 parameter serialization use ordered Maps so PHP insertion order survives round-trips. Native player admission orchestration preserves spawn choice, random icon/stat order, initial item and card processing, original named-account conditions, insert-before-skill hooks, account update, fetch, post-entry events, second safe-spawn check, second save, news and entry cutoff. Thirty-six unmodified enter_battlefield fixtures use explicit synthetic effect/storage ports to verify this sequence; they do not validate the not-yet-ported skill and card effects.

These foundations are not yet enabled in the cloud start transition. Actual world initialization (NPCs, map/trap/shop generation), full card and skill effects, game commands, gameplay templates and settlement remain required. The existing waiting-room runtime deliberately rolls back final-ready while these dependencies are incomplete.

Snapshot missing files remain server.config.php, game.config.php and system.config.php. No secret-bearing source config was copied into Git; future config extraction must use an explicit public gameplay-field allowlist. Production source, MySQL, domains and Workers remain unchanged.
