## 寬度與溢出

對 `topic=movement` 使用瀏覽器動態注入**只讀計量腳本**，記錄 `innerWidth` 與 `document.documentElement.scrollWidth`：

| 視口寬度 | documentElement.scrollWidth | 是否整頁橫向溢出 |
|---:|---:|---|
| 360px | 360px | 否 |
| 390px | 390px | 否 |
| 768px | 768px | 否 |
| 1024px | 1024px | 否 |
| 1440px | 1440px | 否 |

**限定解釋**：表格及子容器可能在自身滾動區域內寬於視口，但沒有造成根文檔橫向滾動。不是每頁每個控件的可用性測試，也不是已登入後的教程實操驗收。
